# mini-quiz-mateusz-kozik

## Opis
Prosta aplikacja mobilna w Android Studio umożliwiająca rozwiązywanie quizu wielokrotnego wyboru.

## Funkcje
- losowanie 5 pytań
- 3 odpowiedzi
- zliczanie punktów
- reset quizu

## Uruchomienie
1. Otwórz projekt w Android Studio
2. Uruchom emulator
3. Kliknij "Run"
